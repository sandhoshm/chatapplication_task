This project is a Multithreaded Chat Application developed using Java Socket Programming and Multithreading concepts. The application follows a client-server architecture where multiple clients can connect to a central server and communicate with each other in real time. The server listens for incoming client connections using ServerSocket and creates a separate thread for every connected client. This multithreading approach allows multiple users to send and receive messages simultaneously without interrupting the communication flow.

The Client program connects to the server using sockets and enables users to send messages through the console. At the same time, a separate reading thread continuously listens for incoming messages from the server. The server broadcasts every received message to all connected clients, creating a group chat environment. This project demonstrates important networking concepts such as socket communication, input/output streams, concurrency, thread handling, and real-time data transmission in Java.

The application is simple, efficient, and useful for understanding the basics of network programming and multithreaded systems. It can be further enhanced by adding features such as usernames, graphical user interfaces, private messaging, encryption, and online user status.
